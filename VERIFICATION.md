## Git и LFS

В изолированном временном Git-репозитории выполнены создание ветки,
несовместимые изменения одной строки, настоящий merge conflict и его разрешение.
Итоговый merge-коммит имеет двух родителей; итоговая ветка — main.
Это проверка сценария, а не история коммитов в пользовательском GitHub:
команды ДЗ 2 нужно выполнить на своём компьютере.

Для двух версий одинаковых бинарных файлов:
обычный Git-объект 2097152 байта; LFS-pointer 132 байта.
Между версиями OID меняется; полноценные рабочие файлы совпадают.
Передача в GitHub LFS с учётной записью пользователя здесь не выполнялась.

Ручное логирование и вариант с артефактами выполнены для всех трёх конфигураций.
Lightning autolog выполнен с отдельной validation-частью.
Сохранены CSV/JSON реальных запусков. Run ID относятся к локальной базе среды
проверки; на вашем компьютере они будут другими. Сама база и её абсолютные
пути не входят в архив. Запуски необходимо воспроизвести локально.
Повторный autolog в выгрузке показывает ту же метрику при фиксированном seed.

Телеметрия MLflow отключена через MLFLOW_DISABLE_TELEMETRY=true;
эксперименты записываются в локальную SQLite.

UI MLflow также запущен локально с одним worker: главная страница вернула HTTP 200.
