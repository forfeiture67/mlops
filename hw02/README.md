# ДЗ 2. Git и разрешение конфликта

Цель: показать staging, коммиты, создание временной ветки, конфликт при слиянии
и его ручное разрешение. Все результаты после слияния остаются в `main`.

Пошаговый сценарий приведён в разделе «ДЗ 2» файла `../GUIDE_WINDOWS.md`.
Файлы `sample.txt` и `conflict.txt` создаются командами на компьютере исполнителя:
это позволяет получить настоящую историю коммитов, а не только итоговые файлы.

В конфликте обе ветки меняют одну и ту же строку: `base` → `main` и `base` → `feature`.
После ручного разрешения файл содержит `main + feature`.
Проверка: `git log --graph --oneline --all`, `git status`, отсутствие маркеров конфликта.
