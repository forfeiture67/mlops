# MLOps: домашние задания 2–5

Репозиторий: https://github.com/forfeiture67/mlops, итоговая ветка `main`.
Файлы первого занятия в корне сохраняются.

| Задание | Папка | Содержание |
|---|---|---|
| ДЗ 2 | `hw02` | Git: коммиты, временные ветки, слияние с конфликтом |
| ДЗ 3 | `hw03` | Сравнение Git и LFS; четыре стадии DVC; локальный remote |
| ДЗ 4 | `hw04` | Классификация digits, блок, модель, загрузчик, обучение, pytest |
| ДЗ 5 | `hw05` | MLflow: ручное логирование, артефакты, Lightning autolog, поиск |

Начать с **GUIDE_WINDOWS.md**. В нём установка, точные команды для каждого ДЗ,
ожидаемые результаты и отдельные коммиты в `main`.
Python 3.12; запуск команд из корня репозитория, кроме явно указанного ДЗ 3.
ДЗ 2 и 5 подготовлены по содержанию примеров; отдельных текстовых требований
для этих двух заданий не было.

Локальное DVC-хранилище подходит по условию преподавателя, но не передаётся через GitHub.
Для воспроизведения с другого компьютера есть детерминированный генератор данных.
Папка `hw05/results` содержит выгрузку реальных запусков, а не базу MLflow;
для просмотра интерактивного UI необходимо выполнить скрипты локально.
