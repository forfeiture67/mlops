# ДЗ 4. Тестирование ML-пайплайна

Задача: распознать цифры 0–9 по 64 пикселям. Используется `load_digits` из
scikit-learn: 1797 наблюдений, дополнительное скачивание датасета не требуется.
Разделение стратифицированное, seed=42, test=20%. Интенсивности делятся на 16.

Модель: DenseBlock(64 → hidden, ReLU) → Linear(hidden → 10), обучение Adam,
CrossEntropyLoss. Тестовая выборка оценивается после завершения обучения.
`hw05` использует эти же компоненты, чтобы логировать рабочий пайплайн.

Из корня репозитория:

```powershell
python -m hw04.train --epochs 10
python -m pytest hw04/tests -v --cov=hw04 --cov-report=term-missing
```

| Mark | Проверка |
|---|---|
| unit | Известные веса блока, градиенты модели, недопустимый hidden |
| data | Типы, диапазоны, классы, раздельность выборок, полнота и порядок батчей |
| property | Формы выходов и конечность значений для генерируемых batch/hidden |
| integration | Изменение весов после шага, точность на известных ответах |
| training | Переобучение малого батча, падение loss, воспроизводимость |
| e2e | CLI отдельным процессом: обучение → файлы → загрузка → та же точность |

Выбрать отдельную группу: `python -m pytest hw04/tests -m training -v`.
Модель сохраняется в `artifacts/model.pt`, метрики — в `artifacts/metrics.json`;
эти генерируемые файлы исключены из Git. Небольшие отчёты в results можно коммитить.
Для coverage тестовые файлы исключены через `.coveragerc`; E2E запускает subprocess,
поэтому его выполнение CLI не полностью учитывается обычным coverage родительского процесса.
